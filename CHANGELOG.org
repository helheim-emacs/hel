* [Unreleased]
** Added

- Extensions can use more of Hel. ~hel-node-producer~ returns the producer
  that the ~hel-node-~ operations take. ~hel-extending-selection~ is non-nil
  while =v= makes motions extend the selection. ~hel-word-motion~,
  ~hel-WORD-motion~, ~hel-sentence-motion~, ~hel-paragraph-motion~,
  ~hel-function-motion~ and ~hel-sexp-motion~ move point over COUNT things
  and return the part of COUNT that is left, as ~hel-motion-source~
  expects. ~hel-treesit-nodes-hull~ returns the smallest range that holds
  a list of tree-sitter nodes.

- =mst=, =mdt=, =mrt= — surround functionality for XML/HTML tags.

- Structural selection in every buffer, with the keys of ~hel-paredit~ and
  Helix. In tree-sitter modes the commands walk the syntax tree. In other
  buffers they use the syntax table: words, strings, comments, brackets,
  sexps and paragraphs.
  - =M-o= / =M-i= (=C-k= / =C-j=) — expand the selection to the enclosing node
    and shrink it back along the same path. Each cursor has its own history.
  - =M-n= / =M-p= (=C-l= / =C-h=) — select the next / previous sibling. They
    keep the direction of the selection.
  - =M-b= / =M-e= — expand the selection with point at its start / end. =M-o=
    runs the same command as =M-b=. Bind =M-o= to
    ~hel-expand-selection-forward~ to get a forward expand.
  - In a Lisp mode the nodes are sexps. Add ~hel-use-lisp-nodes~ to the hook of
    a major mode to treat it as Lisp.
  - =M-a= — select all siblings, a cursor on each.
  - =M-I= (=M-j=) — select all children, a cursor on each.

  The =C-hjkl= keys are bound only when ~hel-want-C-hjkl-keys~ is non-nil.

  =M-o= puts point at the start of the selection. After =v=, =M-n= / =M-p= extend
  the selection, as other motions do.

- ~hel-backward-word-end~ and ~hel-backward-WORD-end~ select back to the end
  of the previous word or WORD, as =ge= and =gE= in Vim. No key is bound to
  them.

- Function, class, argument and comment text objects: =mif= / =maf=,
  =mit= / =mat=, =mia= / =maa=, =mic= / =mac=, and the motions =]f= / =[f=,
  =]t= / =[t=, =]a= / =[a=, =]c= / =[c=.
  On Emacs 31 they use tree-sitter queries, which Hel ships in the
  =queries= directory and which derive from the queries of Helix.

- Entry text object: =mie= / =mae= and the motions =]e= / =[e=. An entry is
  one element of a data structure: an element of a list, a key with its
  value in a dictionary, or a field of a struct. It needs Emacs 31 and
  a tree-sitter parser. A package recipe must include this directory:
  ~:files (:defaults "queries")~. Without a query, the function and comment
  objects use the syntax table, as before.

- Without a tree-sitter query, =mia= / =maa= and =]a= / =[a= find the
  arguments with the syntax table: an argument is the text between two
  commas in parentheses. So they work on Emacs 29 and 30 and in modes
  without a parser. Lisp modes have no such arguments.

- =mb= / =mim= and =mam= select inside and around the closest brackets:
  parentheses, square brackets or curly brackets, whichever lie closest, as
  =mim= in Helix. =mdm= and =mrm= delete and replace them.

- A repeated =mi(=, =ma(= and the other bracket keys select the next brackets
  outward, and a count goes that many brackets outward. =M-i= returns to the
  selection before.

- Pairs of delimiters have an API. ~hel-pair-sources~ maps a key character
  to the producers of its pairs, and ~hel-surround-delimiters~ to what
  =ms= inserts and to its padding. ~hel-function-pair-source~ makes a pair from a function that
  returns four positions, and ~hel-delimiter-pair-source~ from two strings.
  ~hel-pair-at~ and ~hel-pair-parent~ find a ~hel-pair~, and
  ~hel-mark-pair~ selects one.

** Changed

- =mr= replaces only the delimiters and keeps the layout of the pair:
  =mr([= turns =(foo)= into =[foo]=, and brackets on lines of their own stay
  there.

- =md= deletes a delimiter that stands alone on its line with its line, for
  every key, and leaves no blanks at the end of a line.

- Only a programming mode indents the text after a linewise =ms= or after
  =md=. Other modes, such as Markdown, keep the indentation of the text,
  and a linewise =ms= puts the delimiter lines at the least indentation of
  the text.

- ~hel-surround-alist~ is obsolete. Use ~hel-pair-sources~ and
  ~hel-surround-delimiters~. For one release Hel still reads the old
  variable, and its elements win over the new ones. Its default value is
  empty.

- ~hel-surround-4-bounds-at-point~, ~hel-bounds-of-brackets-at-point~,
  ~hel-4-bounds-of-brackets-at-point~, ~hel-bounds-of-quoted-at-point~,
  ~hel-surround-4-bounds-of-html-tag-at-point~ and
  ~hel-surround-search-outward~ are removed. Use ~hel-pair-at~ with the
  producer of a key, ~(hel-pair-producer CHAR)~.

- ~hel-mark-inner-legacy-quoted~ and ~hel-mark-a-legacy-quoted~ are removed.
  In Emacs Lisp, =mi`= and =mi'= select the text between =`= and ='=.

- =mi"= and =ma"= find the string with the cursor on its opening quote or
  right after its closing quote, also where the quote mark is not a string
  quote of the mode, as in ~text-mode~.

- In tree-sitter modes, =mi"=, =mi'= and =mi`= find the strings through the
  query of the language, so a Python ="""docstring"""= is one string with
  three quotes on each side, and =ma"= takes the prefix of =f"text"=.

- =]d= and =[d= go to the next and the previous error or diagnostic
  (~next-error~, ~previous-error~). =]e= and =[e= select entries.

- =]p= and =[p= run the same commands as =}= and ={=. ~hel-forward-paragraph-end~
  and ~hel-backward-paragraph-end~ are removed.

- ~hel-set-region~ is removed. Use ~hel-select~ with a range and a direction,
  or ~hel-motion-select~ for a motion that keeps the mark after =v=.

- The Hel API says "selection" for a selection as a value. ~hel-region~ and
  ~hel-save-region~ are renamed to ~hel-selection~ and ~hel-save-selection~.

- The text object commands for things lose the ~inner-~ part of their name,
  and the ~a-~ part becomes ~around-~: ~hel-mark-inner-function~ is
  ~hel-mark-function~, and ~hel-mark-a-function~ is
  ~hel-mark-around-function~. This holds for words, WORDs, sentences,
  paragraphs, functions, classes, arguments, entries and comments. The
  commands for the text between delimiters, such as
  ~hel-mark-inner-paren~, keep their names.

- Word motions, =_= and the text objects take every character with whitespace
  syntax as a blank, such as a page break, a no-break space and an ideographic
  space. =W= stops at them, and it no longer treats =foo　bar= as one WORD.

- ~hel-line-begin~ and ~hel-line-end~ return the edges of the line at a position
  and leave point alone. They replace ~hel-beginning-of-line~ and
  ~hel-end-of-line~. ~hel-eolp~, ~hel-visual-bolp~ and ~hel-visual-eolp~ are
  removed.

- ~hel-selection~ returns ~(RANGE DIRECTION)~, the arguments of ~hel-select~.
  ~hel-trim-whitespace-from-range~, ~hel-invert-case-in-range~,
  ~hel-replace-chars~, ~hel-read-char-and-replace~ and ~hel-range-visible-p~
  take a range ~(BEGIN . END)~.

- =maf= takes the header comment above the function and the blank lines after
  it, and =maa= takes the comma after the argument, or before the last one.
  A count selects several objects, and a repeated =maf= adds the next function.
   =M-i= returns to the selection before =mi= / =ma=.

- =mif= selects the whole function with its signature, as before, also in
  tree-sitter modes. Helix's =mif= selects only the body.

- The word, WORD, sentence and paragraph objects (=miw= / =maw=, =miW= / =maW=, =mis=
  / =mas=, =mip= / =map=) use the same rules as the function object. A count works
  for all of them, and a repeated key adds the next object. =maw= takes the
  spaces after the word, or before it when the word ends at punctuation or
  at the end of the line. =mas= takes the blanks after the sentence, or before
  it when the sentence ends at the end of the line, and a count stops at the
  end of the paragraph. An around object takes the gap before it when the
  gap after it is empty or ends at a closing bracket or at the end of the
  buffer, so =d= leaves no blank line or separator in front of them.

- =miW= and =maW= leave out the punctuation around a WORD, so =miW= on
  =~foo~.= selects =~foo~=. A separator such as =,= =.= or =:= goes only
  from the end, so =:begin= keeps its colon, and =¿= and =¡= go only from
  the start. A bracket or a quote, =«»=, =„“= and =`'= included, stays
  when its pair is inside the WORD, as in =foo(bar)=, and an apostrophe
  without a pair stays, as in ='foo=. =W=, =B= and =E= do not change.

- ~hel-mark-around-sentence~ takes a count instead of a thing. The functions
  ~hel-mark-inner-thing~, ~hel-mark-a-thing~, ~hel-bounds-of-count-things-at-point~
  and ~hel-bounds-of-complement-of-thing-at-point~ are removed. A package defines
  its own kind of object as a thing: a symbol whose property ~hel-thing-sources~
  lists where its objects come from. Its commands call ~hel-mark-text-object~
  and ~hel-mark-to-thing-edge~, and a rule that holds for one kind is a method
  of a ~hel-thing-~ generic function.

- A producer returns each thing that it finds as a ~hel-thing-instance~
  struct instead of a plist. Build one with ~hel-thing-instance-create~, and
  read it with ~hel-thing-instance-begin~ and ~hel-thing-instance-end~. The
  slot ~data~ holds what the producer keeps about the thing, and only the
  methods of that producer read it with ~hel-thing-instance-data~.
  ~hel-thing-instance-bounds~ returns its range, and
  ~hel-thing-instance-edge~ returns its ~:begin~ or ~:end~ edge.

* [0.13.0]
** Added

- ~hel-want-fine-undo~ option (default ~t~) — use more granular undo steps
  compare to Helix. When ~nil~ all text typed in Insert state is undone as
  a single step, as in Helix. When ~t~ in insert state on typing a single undo
  step finishes at word boundary or when the kind of editing changes between
  typing and deleting. Thus, a single undo typically removes one word.

- ~hel-commit-undo-checkpoint~ — interactive command that finishes the current
  undo step and starts the new one. Helix has it on =C-s= in insert state.
  Hel doesn't bind it by default, to leave the default Emacs experience in
  insert state.

- Display current state in the modeline.

- Integration with ~xref-edit-mode~ and ~grep-edit-mode~ (Emacs 31). Press =i= in
  the =*xref*= or =*grep*= buffer to switch to them and =ZZ= to apply changes and
  return back to read-only mode.

- Integration with [[https://eshelyaron.com/posts/2023-11-17-completion-preview-in-emacs.html][completion-preview-mode]].

** Changed

- Active keymaps were rescanned for Hel’s nested keymaps only at a handful of
  hand-picked points, with one added per package that needed it. Now they’re
  rescanned in ~hel--post-command-hook~. The check costs about 5 μs on my
  machine, which is cheap enough, and we no longer need to manually add
  support for each package.

* [0.12.0]
** Added

- New =r= and =R= commands.

- Integration with [[https://github.com/oantolin/embark][Embark]] package.

** Changed

- *[BREAKING]*
  Scroll commands have been rewritten from the ground up with better
  performance and nice animation. Switched the dependency from the built-in
  pixel-scroll.el to [[https://github.com/jdtsmith/ultra-scroll][ultra-scroll]].

* [0.11.0]
** Added

- Copy with ~universal-argument~ (=M-u y=) appends selection to the last item in
  the ~kill-ring~.

- =gg= / =ge= (=G=) make the *first* / *last* selection (cursor) the main one while there
  are multiple cursors in the buffer.

- =[l= / =]l= — move over pages (=^L= sign in the buffer).

- New key =C-:= to open command palette with only commands relevant to the
  current buffer.

- Keys for Emacs debugger are added.

- Keys for following Emacs built-in modes are added:
  - =comint-mode=
  - =image-mode=
  - =calendar-mode=
  - =diff-mode=

** Changed

- Search commands: ~/~, =?=, =n=, =N=, =*=, =M-*= have been rewritten from the ground
  up. Search matches now remain highlighted in the buffer, and the number
  of matches is displayed in the mode line. You can clear the highlights
  with =Esc= or =;=. Closed folds now open automatically when the cursor lands
  inside them.

- Downcase and upcase commands (=gu= / =gU= or ~`~ / ~M-`~) now accept a numeric
  argument. The cursor no longer moves after these commands.

- =gq= now calls ~fill-paragraph~ instead of ~fill-region~. It is more generic
  and falls back to ~fill-region~ when a selection is active.

- *[BREAKING]*
  =motion= state is renamed to =emacs= state.

- *[BREAKING]*
  =hel-common.el= file is renamed to =hel-lib.el=

- *[BREAKING]*
  ~hel-fake-cursor-specific-vars~ variable is renamed to ~hel-fake-cursor-variables~.

- *[BREAKING]*
  ~hel-unsupported-command~ macro is converted to ~hel-set-unsupported-command~
  function.

- *[BREAKING]*
  All extensions are moved to their own repositories.

- *[BREAKING]*
  =hel-leader= extension is fully rewritten: the [[https://github.com/emacsorphanage/god-mode][God-Mode]] logic is replaced
  with an original one.

** Fixed

- Compatibility issue with Emacs 31. ([[https://github.com/helheim-emacs/hel/issues/17][#17]])

- =Esc= key in text terminal. ([[https://github.com/helheim-emacs/hel/issues/1][#1]])
