* [Unreleased]
** Added

- =mst=, =mdt=, =mrt= — surround functionality for XML/HTML tags.

- Structural selection in every buffer, with the keys of ~hel-paredit~ and
  Helix. In tree-sitter modes the commands walk the syntax tree. In other
  buffers they use the syntax table: words, strings, comments, brackets,
  sexps and paragraphs.
  - =M-o= / =M-i= (=C-k= / =C-j=) — expand the selection to the enclosing node
    and shrink it back along the same path. Each cursor has its own history.
  - =M-n= / =M-p= (=C-l= / =C-h=) — select the next / previous sibling. They
    keep the direction of the selection.
  - =M-b= / =M-e= (=H= / =L=) — select to the start / end of the parent node.
    In Lisp, =H= / =L= select the enclosing sexp, with point at its start / end.
    ~hel-lisp-modes~ lists the Lisp modes.
  - =M-a= — select all siblings, a cursor on each.
  - =M-I= (=M-j=) — select all children, a cursor on each.

  The =C-hjkl= keys are bound only when ~hel-want-C-hjkl-keys~ is non-nil.

  =M-o= puts point at the start of the selection. After =v=, =M-n= / =M-p= extend
  the selection, as other motions do.

- ~hel-backward-word-end~ and ~hel-backward-WORD-end~ select back to the end
  of the previous word or WORD, as =ge= and =gE= in Vim. No key is bound to
  them.

- Function, class, argument and comment text objects: =mif= / =maf=, =mit= / =mat=,
  =mia= / =maa=, =mic= / =mac=, and the jumps =]f= / =[f=, =]t= / =[t=, =]a= / =[a=, =]c= / =[c=.
  On Emacs 31 they use the tree-sitter queries of Helix, which Hel ships
  in the =queries= directory. A package recipe must include this directory:
  ~:files (:defaults "queries")~. Without a query, the function and comment
  objects use the syntax table, as before.

** Changed

- ~hel-set-region~ is obsolete. Use ~hel-select~ with a range and a direction, or
  ~hel-select-motion~ for a motion that keeps the mark after =v=.

- =maf= takes the header comment above the function and the blank lines after
  it, and =maa= takes the comma after the argument, or before the last one.
  A count selects several objects, and a repeated =maf= adds the next function.
   =M-i= returns to the selection before =mi= / =ma=.

- =mif= selects the whole function with its signature, as before, also in
  tree-sitter modes. Helix's =mif= selects only the body.

- The word, WORD, sentence and paragraph objects (=miw= / =maw=, =miW= / =maW=, =mis=
  / =mas=, =mip= / =map=) use the same rules as the function object. A count works
  for all of them, and a repeated key adds the next object. =maw= takes the
  spaces after the word, or before it when the word ends at punctuation or
  at the end of the line. =mas= takes the whitespace after the sentence across
  line ends, but not past the end of the paragraph, and a count stops at the
  end of the paragraph as well.

- ~hel-mark-a-sentence~ takes a count instead of a thing. The functions
  ~hel-mark-inner-thing~, ~hel-mark-a-thing~, ~hel-bounds-of-count-things-at-point~
  and ~hel-bounds-of-complement-of-thing-at-point~ are removed. A package defines
  its own kind of object as a thing: a symbol whose property ~hel-thing-sources~
  lists where its objects come from. Its commands call ~hel--mark-text-object~
  and ~hel--mark-to-thing-edge~, and a rule that holds for one kind is a method
  of a ~hel-thing-~ generic function.

* [0.13.0]
** Added

- ~hel-want-fine-undo~ option (default ~t~) — use more granular undo steps
  compare to Helix. When ~nil~ all text typed in Insert state is undone as
  a single step, as in Helix. When ~t~ in insert state on typing a single undo
  step finishes at word boundary or when the kind of editing changes between
  typing and deleting. Thus, a single undo typically removes one word.

- ~hel-commit-undo-checkpoint~ — interactive command that finishes the current
  undo step and starts the new one. Helix has it on =C-s= in insert state.
  Hel doesn't bind it by default, to leave the default Emacs experience in
  insert state.

- Display current state in the modeline.

- Integration with ~xref-edit-mode~ and ~grep-edit-mode~ (Emacs 31). Press =i= in
  the =*xref*= or =*grep*= buffer to switch to them and =ZZ= to apply changes and
  return back to read-only mode.

- Integration with [[https://eshelyaron.com/posts/2023-11-17-completion-preview-in-emacs.html][completion-preview-mode]].

** Changed

- Active keymaps were rescanned for Hel’s nested keymaps only at a handful of
  hand-picked points, with one added per package that needed it. Now they’re
  rescanned in ~hel--post-command-hook~. The check costs about 5 μs on my
  machine, which is cheap enough, and we no longer need to manually add
  support for each package.

* [0.12.0]
** Added

- New =r= and =R= commands.

- Integration with [[https://github.com/oantolin/embark][Embark]] package.

** Changed

- *[BREAKING]*
  Scroll commands have been rewritten from the ground up with better
  performance and nice animation. Switched the dependency from the built-in
  pixel-scroll.el to [[https://github.com/jdtsmith/ultra-scroll][ultra-scroll]].

* [0.11.0]
** Added

- Copy with ~universal-argument~ (=M-u y=) appends selection to the last item in
  the ~kill-ring~.

- =gg= / =ge= (=G=) make the *first* / *last* selection (cursor) the main one while there
  are multiple cursors in the buffer.

- =[l= / =]l= — move over pages (=^L= sign in the buffer).

- New key =C-:= to open command palette with only commands relevant to the
  current buffer.

- Keys for Emacs debugger are added.

- Keys for following Emacs built-in modes are added:
  - =comint-mode=
  - =image-mode=
  - =calendar-mode=
  - =diff-mode=

** Changed

- Search commands: ~/~, =?=, =n=, =N=, =*=, =M-*= have been rewritten from the ground
  up. Search matches now remain highlighted in the buffer, and the number
  of matches is displayed in the mode line. You can clear the highlights
  with =Esc= or =;=. Closed folds now open automatically when the cursor lands
  inside them.

- Downcase and upcase commands (=gu= / =gU= or ~`~ / ~M-`~) now accept a numeric
  argument. The cursor no longer moves after these commands.

- =gw= now calls ~fill-paragraph~ instead of ~fill-region~. It is more generic
  and falls back to ~fill-region~ when a selection is active.

- *[BREAKING]*
  =motion= state is renamed to =emacs= state.

- *[BREAKING]*
  =hel-common.el= file is renamed to =hel-lib.el=

- *[BREAKING]*
  ~hel-fake-cursor-specific-vars~ variable is renamed to ~hel-fake-cursor-variables~.

- *[BREAKING]*
  ~hel-unsupported-command~ macro is converted to ~hel-set-unsupported-command~
  function.

- *[BREAKING]*
  All extensions are moved to their own repositories.

- *[BREAKING]*
  =hel-leader= extension is fully rewritten: the [[https://github.com/emacsorphanage/god-mode][God-Mode]] logic is replaced
  with an original one.

** Fixed

- Compatibility issue with Emacs 31. ([[https://github.com/helheim-emacs/hel/issues/17][#17]])

- =Esc= key in text terminal. ([[https://github.com/helheim-emacs/hel/issues/1][#1]])

* [0.10.0]
** Added

- =gv= — restore last multiple cursors positions.

** Changed

- =p= and =P= will paste on the separate line if selection is linewise (i.e. made
  with =x=).

- =gi= (~imenu~) moved to =go= to leave =gi= for LSP’s "go to implementation".

- =gD= (~xref-find-references~) moved to =gr= to leave =gD= for LSP's "go to
  declaration".

- *[BREAKING]*
  ~hel-surround-alist~ variable format has been changed.

- *[BREAKING]*
  The mechanism for switching the shape and color of the main cursors has been
  reworked. The single variables for main cursor appearance in each state are
  removed and replaced with two variables: main cursor shape and face.

  - Removed:
    - ~hel-normal-state-cursor~
    - ~hel-insert-state-cursor~
    - ~hel-motion-state-cursor~

  - Added:
    - Shape:
      - ~hel-normal-state-cursor-type~
      - ~hel-insert-state-cursor-type~
      - ~hel-motion-state-cursor-type~
    - Faces:
      - ~hel-normal-state-main-cursor~
      - ~hel-insert-state-main-cursor~
      - ~hel-motion-state-main-cursor~
