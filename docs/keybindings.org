#+title: Keybindings Reference

You actually don't need this file. Emacs has an absolutely wonderful help system
that neither Vim nor Helix has anything close to — it is self-documented.

You can always place cursor on any variable or command you're interested in, press
=: helpful-at-point= (or =M-x helpful-at-point=) from [[https://github.com/Wilfred/helpful][helpful]] package to see the full
documentation about it. Bind it to key for more convenient access. Vim uses =K= key
for such things (which is available while there is only one cursor in the buffer),
another good choice is =M= since it's unused in Hel.
#+begin_src emacs-lisp
(hel-keymap-set emacs-lisp-mode-map :state 'normal
  "M" 'helpful-at-point)
#+end_src

Hel keybindings are defined in the =hel-keybindings.el= file. Using the advice above,
you can read the documentation for any command bound to a key you’re interested in.

* Emacs state

Emacs state is the default state for special buffers: grep results, error
lists, file managers — anything not intended for text editing. A simple
heuristic is used: if any letter key is not self-inserting, Hel enables
Emacs state; otherwise, it uses Normal state.

In Emacs state Hel provide service keys to control Emacs itself.

#+begin_quote
[!IMPORTANT]
~universal-argument~ is rebound to =M-u= because =C-u= is used for scrolling and =M-u=
by default is bound to ~upcase-word~, for which Hel has itself version on =M-`= or =gU=.
#+end_quote

- =:= :: Emacs analogue of a command palette. (Native key is =M-x=)

- =C-:= ::
  Open the command palette with only the commands that make sense in the
  current buffer. (Native key is =M-X=)

- =SPC= :: Leader key (if ~hel-leader~ extension is installed)

- =i= ::
  Switch to Normal state. This allows you to select and copy arbitrary text
  in special modes. To switch back, use =zx= or =C-x C-s= (~hel-emacs-state~).

** Windows

- =C-w s= / =C-w v= :: Split window *horizontally* / *vertically*.

- =C-w c= ::
  Close current window, if it was the last window on the tab — close the tab.

- =C-w d= :: Kill current buffer.

- =C-w q= :: =C-w d= + =C-w c=

- =C-w o= :: Close all other windows.

- =C-w w= :: Cycle to the next window.

- =C-w= + =h=, =j=, =k=, =l= :: Go to the window toward the direction.

- =C-w= + =H=, =J=, =K=, =L= :: Move window in direction.

- =C-w RET= :: Display the buffer of the next command in the same window.

- =C-w n= :: Display the buffer of the next command in a new window.

- =C-w r= :: Revert buffer.

- =C-w := / =C-w C-:= ::
  Run a command, and display its buffer in another window. =C-w C-:= offers
  only the commands that make sense in the current buffer.

All window commands also duplicated with =C-= prefix for convenience: =C-w C-s=,
=C-w C-v=, etc.

A secondary prefix for window commands is available on =C-c w=. It is useful when
the =C-w= prefix is unavailable, such as in terminal emulators, ~picture-mode~, and
similar modes.

** Scrolling

Scrolling commands are taken from Vim.

- =C-d= / =C-u= ::
  Scroll *down* / *up* half of the page. If a numeric prefix is provided, scroll
  this amount of lines and remember it for further use. To reset it use 0
  prefix. (like in Vim)

- =C-f= / =C-b= :: Scroll *down* / *up* full page.

- =C-e= / =C-y= :: Scroll *down* / *up* COUNT lines.

- =zt= / =zb= :: Scroll current line to the *top* / *bottom* border of the screen.

- =zz= :: Scrolls current line to the eye level.

  If you want Vim default behavior set following variable *before* requiring Hel:
  #+begin_src emacs-lisp
  (setopt hel-want-zz-scroll-to-center t)
  #+end_src

** Buffers

- =C-w r= :: Revert current buffer.

- =C-w d= :: Kill current buffer.
- =C-w q= :: Kill current buffer and close window.

- =C-w z= ::
  Burry current buffer: put it the end of the list of all buffers.
  Mnemonics: =z= is the last letter.

- =[b= / =]b= :: *previous* / *next* buffer

- =C-w x= :: ~scratch-buffer~

* Normal state

All keys available in Emacs state are also work in Normal state.

** Motions

- =h=, =j=, =k=, =l= :: Arrows.

- =w=, =b=, =e= :: word motions
- =W=, =B=, =E= :: WORD motions

- =f= / =F= :: Find *next* / *previous* char.
  While hints are active use =n= / =N= to repeat motion.

- =t= / =T= :: Till *next* / *previous* char.
  While hints are active use =n= / =N= to repeat motion.

- =gh= / =gl= :: Move to the *beginning* / *end* of a line.

- =gs= :: Move to the beginning of a line skipping indentation.

- =gg= ::
  - Move to the beginning of the buffer.
  - With numeric argument go to N/10 of the way from the beginning.
  - With multiple cursors make the first selection (cursor) the main one.

- =ge= or =G= ::
  - Move to the end of the buffer.
  - With a numeric argument, go to line N.
  - With multiple cursors make the last selection (cursor) the main one.

- =]= and =[= keys :: Every =]= key selects from point to the end of the
  object under the cursor, and every =[= key selects from point to its start.
  When point is already there, the key selects the whole next or previous
  object. So the first =]f= finishes the current function, and every next
  =]f= selects one whole function. A count goes on over that many objects.

  - =[f= / =]f= :: Function, with its decorators.
  - =[t= / =]t= :: Class or type.
  - =[a= / =]a= :: Argument or parameter, without the comma.
  - =[e= / =]e= :: Entry of a data structure, without the comma.
  - =[c= / =]c= :: Block of comment lines.
  - =[s= / =]s= :: Sentence.
  - =[p= / =]p= :: Paragraph. These keys differ from the others: they work the
    same as ={= / =}=.

- ={= / =}= :: Select from point to the start of the current paragraph, or to
  the start of the next one. When point is already at the start of the
  current paragraph, ={= goes to the start of the previous one. With no
  paragraph left, the keys select to the edge of the buffer.

- =(= / =)= ::
  When there is only one cursor in the buffer, these keys work as =[s= / =]s=
  in major modes derived from ~text-mode~, and as =[f= / =]f= in major modes
  derived from ~prog-mode~.

- =[l= / =]l= :: Move over pages (=^L= sign in the buffer).

- =[d= / =]d= :: Go to the previous / next error or diagnostic, or to the
  previous / next match of a grep or compilation buffer (~previous-error~ /
  ~next-error~).

*** Easymotion

- =gw= / =gb= ::
  Place hints at all words *forward* / *backward* and select the chosen one.

- =gW= / =gB= ::
  Place hints at all WORDS *forward* / *backward* and select the chosen one.

- =gj= / =gk= :: Go to line *down* / *up*.

** Changes

- =i= / =a= :: *insert* / *append*: Switch to Insert state *before* / *after* selection.

- =I= / =A= :: *Insert* / *Append*: Switch to Insert state at the *start* / *end* of the line.

- =o= / =O= ::
  Open: add new line *bellow* / *above* the current line and switch to Insert state.

- =d= :: Cut selection: delete it from buffer and put into ~kill-ring~.

- =D= :: Delete selection.

- =c= ::
  Change. Delete selection and switch to Insert state. When executed in empty
  line — insert indentation and switch to Insert state.

- =u= / =U= :: *undo* / *redo*.

- =y= ::
  - Copy the selection into ~kill-ring~.
  - With =M-u= (~universal-argument~) append selection to the last item in the
    ~kill-ring~.

- =p= / =P= :: Paste last entry from ~kill-ring~ *after* / *before* selection.

- =C-p= / =C-n= ::
  Replace just-pasted text with *next* / *previous* element from ~kill-ring~.
  This is wrappers around Emacs built-in ~yank-pop~ command.

- =r= ::
  - With active selection replace every character in it with typed one.
  - Without active selection replace count characters *before* point.

- =R= ::
  - With active selection replace it with last entry from ~kill-ring~. You
    can use =C-p= / =C-n= immediately after this command to choose next/previous
    element from the ~kill-ring~.
  - Without active selection replace count characters *after* point.

- =~= :: Invert case of characters.

- =`= / =M-`= or =gu= / =gU= ::
  Convert selection to *lower* / *upper* case. With no selection convert count
  characters after cursor. (Useful, for example, when you want to capitalize
  only the first letter of a word — place cursor before word and press =gU=
  with no selection.)

- =] SPC= / =[ SPC= :: Add empty line *bellow* / *above* the current line.

** Multiple cursors

- =M-right mouse= ::
  Add a secondary cursor at the click, or remove the cursor that is there.

- =C= / =M-c= :: Copy selection (cursor) *down* / *up*.

- =s= ::
  Interactively enter regexp and create cursors for all matches withing
  active selections.

- =S= ::
  Interactively enter regexp and create cursors for complements to all
  matches to regexp withing active selections.

- =M-s= :: Split selections into separate lines.

- =gv= :: Restore last multiple cursors positions.

*** Keys active while there are multiple cursors

- =K= / =M-K= :: *Keep* / *remove* selections matching to regexp.

- =,= :: Remove all secondary cursors.

- =M-,= :: Remove main cursor.

- =&= :: Align selections.

- =M-minus= :: Merge all selections into single one.

- =(= / =)= :: Rotate main selection *backward* / *forward*.

- =M-(= / =M-)= :: Rotate selections content *backward* / *forward*.

** Selections

- =v= :: Toggle extend selection.

- =x= / =X= ::
  Select current visual (if ~visual-line-mode~ is active) or logical line on
  first invocation. On subsequent calls *extend* / *contract* linewise selection
  down when cursor is at the end of the selection, or up when cursor is at the
  beginning of the selection.

- =%= :: Select whole buffer.

- =;= :: Collapse selection onto a single cursor.

- =M-;= or =g;= :: Exchange point and mark.

- =_= :: Trim the whitespace from both ends of the selection.

- =J= :: Join lines inside selection.

*** Structural selection

These keys select the nodes of the syntax tree in a buffer with
a tree-sitter parser. In other buffers, a sexp takes the place of a node,
and the enclosing bracket pair takes the place of the parent node.

- =M-o= or =C-k= :: Expand the selection to the enclosing node. In a buffer
  without a parser, the steps are the word, the string, the comment, the
  brackets, the sentence and the paragraph.

- =M-i= or =C-j= :: Shrink the selection back along the path of =M-o=, or to
  the first child.

- =M-n= or =C-l= :: Select the next sibling node.

- =M-p= or =C-h= :: Select the previous sibling node.

- =M-b= :: Expand the selection to the enclosing node, with point at its start.

- =M-e= :: Expand the selection to the enclosing node, with point at its end.

- =M-a= :: Select all sibling nodes, a cursor on each.

- =M-I= or =M-j= :: Select all child nodes, a cursor on each.

The =C-h=, =C-j=, =C-k= and =C-l= keys are bound only when
~hel-want-C-hjkl-keys~ is non-nil.

*** Mark

Here the word "mark" is used as synonym to "select", to form the mnemonic
rule for =m= prefix. Also, this is in line with Emacs tradition which has
commands like ~mark-word~ which use the word "mark" in this particular sense.

- =mw=, =mW= or =miw=, =miW= :: Mark the word/WORD.

- =maw=, =maW= :: Mark the word/WORD with the spaces after it, or before it
  when no spaces follow. The spaces stay on the line of the word.

- =m.= or =mis= :: Mark the sentence. A count selects several sentences of
  the same paragraph.

- =mas= :: Mark the sentence with the whitespace after it, or before it when
  it is the last sentence of the paragraph.

- =mp= or =mip= :: Mark the paragraph as whole lines.

- =map= :: Mark the paragraph with the blank lines after it, or before it
  when it is the last paragraph.

- =mf= or =mif= :: Mark the function with its signature, on whole lines when
  no other code shares them.

- =maf= :: Mark the function with its header comment and the blank lines
  after it.

- =mt= or =mit= :: Mark the class or type.

- =mat= :: Mark the class or type with its header comment and the blank
  lines after it.

- =mA= or =mia= :: Mark the argument or parameter.

- =maa= :: Mark the argument with the comma and the space after it, or
  before it on the last argument.

- =mie= :: Mark the entry of a data structure: an element of a list or an
  array, a key with its value in a dictionary, or a field of a struct.

- =mae= :: Mark the entry with the comma and the space after it, or before
  it on the last entry.

- =mc= or =mic= :: Mark the block of comment lines: whole lines, with their comment
  markers.

- =mac= :: Mark the block of comment lines with the blank lines after it, as
  =map= does for a paragraph. A comment after code takes only the spaces on
  its line.

The function, class, argument, entry and comment objects use tree-sitter
queries on Emacs 31 and later, in a buffer with a tree-sitter parser. In
other buffers, the function and comment objects work through the syntax
table, and the class, argument and entry objects show a message. With a
count, these keys mark several objects. When you press the same key again,
it adds the next object, and =M-i= removes it.

- =m"=, =m'=, =m`= or =mi"=, =mi'=, =mi`= ::
  Mark inside ="= / ='= / =`= quotes.

- =ma"=, =ma'=, =ma`= ::
  Mark around ="= / ='= / =`= quotes.

- =m(=, =m)= or =mi(=, =mi)= :: Mark inside =(= =)=.
- =ma(=, =ma)= :: Mark around =(= =)=.

- =m[=, =m]= or =mi[=, =mi]= :: Mark inside =[= =]=.
- =ma[=, =ma]= :: Mark around =[= =]=.

- =m{=, =m}= or =mi{=, =mi}= :: Mark inside ={= =}=.
- =ma{=, =ma}= :: Mark around ={= =}=.

- =m<=, =m>= or =mi<=, =mi>= :: Mark inside =<= =>=.
- =ma<=, =ma>= :: Mark around =<= =>=.

- =mi= + =!=, =@=, =#=, =$=, =%=, =^=, =&=, =*=, =~=, ~=~, =_= ::
  Mark the inner part of the region enclosed in this characters.

- =ma= + =!=, =@=, =#=, =$=, =%=, =^=, =&=, =*=, =~=, ~=~, =_= ::
  Mark the whole region enclosed in this characters.

- =mb= or =mim= :: Mark inside the closest brackets: =( )=, =[ ]= or ={ }=,
  whichever lie closest.
- =mam= :: Mark around the closest brackets.

A repeated bracket key selects the next brackets outward, and a count goes
that many brackets outward: =2mi(= selects inside the second parentheses
around the cursor. =M-i= returns to the selection before.

** Surround

- =mm= :: Go to matching bracket.

- =ms= :: Surround selection.

  - Left brackets — =(=, =[=, ={= — add extra spaces around the surrounded region.
    If the selection is linewise (make with =x=), the delimiters are placed on
    separate lines.

  - Right brackets — =)=, =]=, =}= — do the opposite: they remove all spaces or
    newlines from the selection and are inserted tightly.

- =md= :: Delete surround. Left brackets — =(=, =[=, ={= — also delete the
  spaces inside the brackets, right brackets delete only the brackets.
  A delimiter alone on its line goes with its line. =mdm= deletes the
  closest brackets.

- =mr= :: Change (replace) surround. Only the delimiters change: the spaces
  and the line breaks inside the pair stay.

*** Surround with HTML/XML tag

- =mst= :: Surround selection with HTML/XML tag.

  Type ~div class="box"~​ and selection will be wraped in ~<div class="box">~
  and ~</div>~.

  With linewise selection (made with =x=) tags will be placed on the
  separate lines.

- =mdt= :: Ask for tag and delete it.

  Type ~div~​ and enclosing ~<div class="box">~ and ~</div>~ tag will be deleted.

  An empty input deletes the nearest enclosing tag.

- =mrt= :: Replace one tag with another. An empty input means the nearest
  enclosing tag.

** Search

- =/=, =?= :: Search for regex pattern *forward* / *backward*.

- =*= ::
  Construct regexp from all current selections and store it in the ~/~ register.
  Auto-detect word boundaries at the beginning and end of the search patterns.

- =M-*= ::
  Construct regexp from all current selections and store it in the ~/~ register.

- =n= / =N= :: Select *next* / *previous* match to the regexp from the ~/~ register.

** Jumplist

- =C-s= :: Save current main cursor position to the mark-ring.

- =C-o= / =C-i= ::
  Go-to previous/next position in the mark-ring. Read help for
  ~hel-backward-mark-ring~ command.

- =C-S-o= / =C-S-i= ::
  Go-to previous/next position in the ~global-mark-ring~ (read about
  it in Emacs manual).

** Miscellaneous

- =zx= :: save buffer

- =gc= :: comment selection

- =go= :: ~imenu~
- =ga= :: Display various information about the position at cursor:
  character code point, faces, overlays, etc.

- =zn= :: Narrow buffer to selection.
- =zw= :: Remove narrowing.

- =gq= :: Fill each of the paragraphs in the region.
- =gQ= :: Fill the region as if it were a single paragraph.

- =gf= :: Open file path under cursor (like in Vim)
- =gx= :: Open URL under cursor (like in Vim)

- =[ SPC= / =] SPC= :: Add empty line *above* / *below*.

** Xref (Emacs go-to definition framework)

- =gd= :: Jump to definition.

- =C-w gd= :: Jump to definition in another window.

- =gr= :: Find all references.

- =[x= / =]x= ::
  Go to the *previous* / *next* position in xref history. It appeares to be very
  handy to have these positions in a stack separate from the jumplist.

* Insert state

In Insert state Hel doesn’t bind any keys by default, so you get the standard
Emacs editing experience here.
